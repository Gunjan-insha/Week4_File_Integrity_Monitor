# Week 4 - File Integrity Monitor

## Description
This project is a Python-based File Integrity Monitor that detects changes in files inside a selected folder using SHA-256 hashing.

## Features
- Detects newly added files
- Detects modified files
- Detects deleted files
- Uses SHA-256 hashing
- Simple command-line interface

## Tools Used
- Python 3
- hashlib
- os

## How to Run
1. Run the Python file.
2. Enter the folder path.
3. Press Enter after making file changes.
4. The program displays added, modified, or deleted files.

## Output
The program compares two scans of the folder and reports any file changes.
